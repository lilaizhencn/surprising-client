# C2C 订单聊天

C2C 入口接入交易 Gateway 的会话与订单，使用现有交易登录、令牌刷新和生物解锁生命周期，不连接 social 服务。

`RealtimeClient` 在现有行情连接上管理 `c2c.inbox` 和当前 `c2c.messages`，没有第二条聊天 WebSocket。公开行情和私有交易订阅的重建不会移除聊天；聊天关闭不会取消行情。认证完成后才发聊天订阅，重连使用原字符串游标，交易账号切换不继承上一账号会话。聊天通知进入独立事件流，聊天错误不会落入交易行情错误处理。

页面提供会话搜索、未读、订单入口、商家咨询、最近消息及向前分页、实时消息与订单事件、已读、文字、JPG/PNG/PDF 附件、图片预览和保存、既有快捷回复。订单详情只读取实际字段，聊天不会触发付款确认或资产释放。私有图片和 PDF 使用交易鉴权接口，客户端没有 R2 配置或密钥。

发送前将请求号、正文和附件 ID 保存到当前用户/会话的系统安全存储。响应未知时保留原请求，用户点击重试先查询回执；已提交只恢复原消息，UNKNOWN 才重发同一正文和请求号。HTTP API 不自动重试网络失败的消息或上传。上传重试复用原附件 ID，未确认文件不会作为成功附件发送。消息依照已提交的精确 int64 标识排序，事务起始时间倒置不会颠倒消息。

验证记录见 [c2c-chat-client-20261020.json](validation/c2c-chat-client-20261020.json)。Flutter 3.44.4 / Dart 3.12.2，工作区和仅包含本次暂存改动的独立副本均通过 analyze、391 项测试，10 项现有条件测试跳过。新覆盖包含 7 项 API、5 项真实本机 WebSocket、8 项页面测试，页面检查 320/390 宽度、明暗主题和键盘弹出。既有算法单未提交改动保留在工作区，没有混入本次提交。

尚未安装此新版本到手机，也未发布后端。原生文件选择/保存交互及手机连测试服务器的完整验收需要后续执行；本次不把 Widget 测试当作真机或实际 R2 联调。Web 与后端的真实 PostgreSQL、HTTP、共享 WebSocket 和 R2 验证分别保存在相应项目。

后续补充：最终完整测试为 394 项通过、10 项条件跳过，analyze 无问题。已读请求在途时合并新的已见水位，后台及生物锁定期间不提前确认，返回可见会话后补发；会话列表订阅失败也可在原连接上重试。
