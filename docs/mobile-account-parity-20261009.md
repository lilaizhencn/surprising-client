# 移动端账户功能进度（2026-10-09）

## 已实现

- 资产总览继续使用统一 AppState 和账户估值；资金账户余额来自与 Web 相同的 `/api/v1/gateway/account/balances`，按服务端资产精度解释可用和冻结单位。
- 充值币种和网络来自 `/api/v1/wallet/assets?operation=deposit`，地址使用 `/api/v1/wallet/deposit-address`；支持地址二维码、复制、Memo / Tag 和保存二维码。不猜测网络，不把托管链上余额当作交易所资金账户余额。
- 提现规则来自服务端 withdrawal catalog；划转覆盖资金账户和六个产品账户，使用整数单位检查精度与范围，保留未知结果的幂等保护。
- 资金与交易记录按资金流水、产品流水、划转、资金费、充提及成交/订单分类，分页与过滤跟随服务端结果。
- 安全中心补齐设备、IP、会话、登录方式、密码、MFA 恢复和 API Key 控制；新 Key 默认为 READ，密钥仅在创建结果中显示。
- 身份认证支持服务端选择的 SELF / SUMSUB / VERIFF，个人及企业资料、国家选择、证件日期与材料管理。第三方核验使用应用内 WebView，摄像头和麦克风权限按实际核验请求授权。
- 账户切换、退出和页面销毁后丢弃过期的资产、地址、记录及认证结果；用户界面使用友好的错误提示。
- 复用已提交的单一全局 WebSocket；新增账户页面不自行建立连接。
