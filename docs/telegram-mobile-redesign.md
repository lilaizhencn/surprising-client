## Telegram 登录

- 登录及注册都提供 Telegram 按钮；系统浏览器授权，领取凭据只放内存，关闭页面后不接受迟到的会话。
- 沿用 AppState 的登录会话、私有数据加载、持久化和现有二次验证，登录后优先显示 `displayName`。无密码、无邮箱账户可以解析及持久化。
- 后端接口与配置参见后端 `docs/telegram-login.md`。未配置时按钮禁用；授权失败、取消或过期不写入会话。
- 2026-10-20：完整 `flutter test` 376 项通过，10 项依赖真实交易环境的测试按已有条件跳过；`flutter analyze` 无问题。后续 UI 变更后需要重新执行相应验收。
- 真实 Telegram 授权尚待完成；Android/iOS 原生运行证据见下文。

## 完整权益与今日收益接入

首页、资产总览、资金账户、交易账户和单产品筛选统一读取本人认证的 `/api/v1/portfolio/income`，不再把只有现金的 product balance 当作包含浮盈亏的总权益。资金账户与 SPOT 共用现金只计一次；明细可用余额、提现 MAX 和划转仍使用权威实时资金接口，收益估值不能用于提交资金操作。

服务端以 UTC+08:00 业务日的日初和共同分钟切点计算，剔除按发生时历史实际价格估值的外部本金；产品内外部划转按所选范围判断。百分比为按毫秒停留时间加权的 Modified Dietz 估计；无正资本基数时不显示百分比。后端 SQL、重建和价格完整性契约见后端 `docs/portfolio-income.md`。

客户端严格校验金额字符串、完整账户集合、业务日、状态和切点时间。每 30 秒刷新，用服务端生成时间加单调经过时间限制 120 秒有效期，跨日和超时会更新为未知，不因手机时区或时间调整延长有效期。失败刷新、注销和换号清除旧估值，迟到响应还需通过当前用户和会话代数检查。隐私开关同时隐藏收益金额和百分比。

真实网关联调发现设备标识需为 UUID，旧的 mobile 前缀标识会导致 AuthService 拒绝。现用安全随机 UUIDv4，并将旧本地非 UUID 标识一次替换后持久化。回归先复现旧格式失败，再验证重新启动复用同一 UUID；实际 App ApiClient 已通过本地专用数据库的注册、登录、刷新、近期认证查询、收益查询与注销。测试不记录会话令牌。

最新自动化与原生收益集成证据见 `validation/portfolio-income-20261020.json`。专用网关原生测试使用明确标记的受控分析投影，不声称是生产账户或本轮实际 Core 下单；已提交 Archive 到 SQL 的真实链路另由后端集成测试验证。


2026-10-20 收益接入的最终验证：452 项完整 Flutter 测试通过，11 项外部环境用例跳过，analyze 无问题；设备 UUID 的真实网关注册/登录/刷新/安全上下文/收益查询/注销单独通过。Android 和 iOS 均运行真正的 SurprisingClientApp，完成深浅色首页及资产账户筛选 3 个场景并采集系统截图，接口金额与页面一致。受控分析投影、测试会话和私有定义文件已清理；不把该受控投影称为本轮实际 Core 下单。完整证据见 [收益与设备契约验收](validation/portfolio-income-20261020.json)。真实 Telegram 授权与 iOS 实机防截图等外部验收项尚未通过，因此仍不合并主分支。


汇总估值与逐币明细有独立的数据就绪状态：已知汇总金额不能证明明细已加载。当前账户的资金/产品明细和精度全部就绪后，空列表才显示“暂无资产”；否则保留真实汇总并提示明细同步中，避免把接口缺失误报为空资产。回归覆盖汇总已知、明细未知，以及资金明细就绪后再次失效的切换。


## 2026-10-21 视觉与交互精修

对照桌面的首页、资产、划转及五张充值参考图，再次核对真实原生页面。首页与资产页共用金额、计价币种和今日收益组件，数字使用等宽数字特性，计价选择保留完整点击范围；收益在浅色主题使用更清晰的绿色，隐藏资产后同时隐藏涨跌颜色，避免从颜色推断盈亏。大字体下收益允许自然换行。

共享搜索支持清空并恢复列表、提交后收起键盘、点击外部或滑动列表收起键盘。回归覆盖 320/392 宽度、深浅主题与 100%/150% 字体，另覆盖长期权名称与大幅涨跌数字；保留六位币种精度的 MAX、数量键盘、待确认锁定和账户隔离。隐藏收益颜色用例已在精修前版本复现两项失败，再在修复版本通过。
